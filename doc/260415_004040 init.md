```
38 : 2 : 1 : 124 : 120 : 101

```

### Meaning:


------

### ⚠️ What is that extra `1`?

You noticed:

```text
38:2:1:124:120:101
        ↑
```

That `1` is part of ISO 8613-6’s *optional fields*.

In practice:

- Most terminals ignore it
- It can represent things like:
  - color space ID
  - or be a placeholder

👉 In real-world parsing:

> Treat both of these as equivalent:
>
> - `38;2;R;G;B`
> - `38:2:R:G:B`
> - `38:2:1:R:G:B`

So you usually want:

```rust
if subparams[0] == 38 && subparams[1] == 2 {
    let rgb = match subparams.len() {
        5 => (subparams[2], subparams[3], subparams[4]),
        6 => (subparams[3], subparams[4], subparams[5]), // skip the extra field
        _ => ...
    };
}
```
